# Version 0.1.0

Offline Markdown reports in Word, PDF, and self-contained HTML with reusable templates, charts, references, CLI, and MCP..

Local verification: 29 tests passed; 95% measured coverage; Ruff lint and formatting checks passed. README quick start was exercised with fictional data.

## Known limitations

Equations use a MathText subset rendered as images. DOCX page and contents fields require refresh in a supporting editor. Pagination depends on installed fonts. Footnote text is flattened. Optional watch mode and Mermaid rendering are not included. PDF requires local Pango and suitable fonts.

See README and AGENTS.md for installation, configuration, machine-readable CLI/MCP interfaces and operational boundaries.
